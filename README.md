## ✨ Características del Portafolio
* **Diseño Moderno y Oscuro:** Interfaz minimalista con estética dark-mode, acentos en tonos fucsia y cian, y tipografías cuidadas.
* **100% Responsivo:** Adaptado mediante utilidades de Tailwind CSS para verse perfecto en dispositivos móviles, tablets y computadores de escritorio.
* **Tarjetas Interactivas de Proyectos:** Enlaces directos a los despliegues de mis aplicaciones web en la nube, con efectos visuales dinámicos.
* **Sección de Contacto Directo:** Enlace rápido optimizado con protocolo `mailto:` para facilitar la comunicación vía correo electrónico.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
El sitio ha sido desarrollado utilizando un stack moderno y eficiente basado en:
* **HTML5:** Estructuración semántica limpia y accesible.
* **Tailwind CSS (v4 via CDN):** Estilos avanzados, diseño de grillas responsivas, efectos hover y transiciones fluidas.
* **Git & GitHub:** Control de versiones y despliegue automatizado mediante GitHub Pages.

## 📂 Estructura de Proyectos Destacados
En la sección de proyectos de la interfaz se encuentran enlazados trabajos como:

2. **Editor de Código Web:** Herramienta interactiva de desarrollo asistido con capacidades gráficas.
